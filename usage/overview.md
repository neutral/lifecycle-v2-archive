# Usage

## Purpose

Use this folder for operating docs that travel alongside the methodology —
both in this repository and in every target install, where the same content
lands at `.lifecycle/usage/`.

Each subfolder owns one topic:

- [tools/](tools/overview.md) — operating the optional `lt` CLI (installed
  from npm as `@neutral/lifecycle-tools`): command surface, the
  gate-to-command mapping for agents, and the human inspection guide.
