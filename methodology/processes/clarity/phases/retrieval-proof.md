# Retrieval Proof

## Purpose

Use Retrieval Proof to verify that Context can be found cheaply after Clarity.

This proof is not Delivery proof for a work delta. It proves route and review
adequacy for future retrieval.

Retrieval Proof checks whether the updated Context surface can be used through
the Context contract without reopening the Clarity records. Clarity records may
explain what was checked, but current Context entries must carry the durable
route, role, relation, review, freshness, and promotion-pressure meaning future
agents need.

## Checks

Run or manually perform checks for:

```text
stable Context IDs preserved exactly once
no unintended root-flat corpus files remain when an atlas is required
every Context folder has overview.md
area and cluster overviews point to the right entries
canonical references are findable from retrieval keys
review_status and freshness labels are honest
promotion pressure is visible
related surfaces and context_relations are shaped correctly
```

## Exit

Exit when the Context Review Packet records passed, blocked, skipped, or
deferred results for each required retrieval check.
