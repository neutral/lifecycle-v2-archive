# Canonicalization

## Purpose

Use Canonicalization to decide which Context should govern future judgment.

Canonicalization should reduce repeated interpretation. It should not flatten
all rationale into one oversized page.

## Actions

Do these when admitted:

```text
choose canonical Context references
link rationale leaves to canonical entries
mark superseded or stale entries honestly
record tensions instead of hiding them
split entries that own multiple durable jobs
merge entries that only preserve source page boundaries
```

## Exit

Exit when future agents know which entry governs and which entries explain,
qualify, or conflict with it.
