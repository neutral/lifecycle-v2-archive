# Promotion Pressure

## Purpose

Use Promotion Pressure to keep Context from becoming the home for all semantic
authority.

Context may identify meaning that belongs later in Intent, Assurance,
Blueprint, or Description. Clarity records that pressure; it does not silently
perform the next process or update every surface.

## Routing

Record pressure toward:

```text
Intent when Context implies intended behavior, non-goals, roles, or acceptance
meaning
Assurance when Context implies invariants, safety obligations, risk
constraints, or required checks
Blueprint when Context implies structure, state flow, dependency direction, or
interface boundaries
Description when Context implies local implementation responsibility,
non-responsibility, sensitive edges, or safe modification guidance
```

## Exit

Exit when every pressure item is recorded as candidate, deferred, rejected, or
blocked with a reason and no narrower surface was updated by accident.
