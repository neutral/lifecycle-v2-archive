# Source Inventory

## Purpose

Use Source Inventory to classify material before it enters Context.

Inventory is interpretation, not import. Old source paths, page boundaries,
wiki structure, and process records are source treatment facts unless current
Context admits them as product meaning.

## Questions

Answer:

```text
What current Context already exists?
What source material exists?
Which source material is authoritative, informative, stale, duplicate, or
excluded?
Which entries are candidate canonical references?
Which entries are candidate rationale leaves?
Which items conflict or need founder-dev decision?
```

## Exit

Exit when the Source Inventory supports the review depth in the Clarity
Boundary.
