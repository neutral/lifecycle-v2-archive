# Clarity Gates

## Purpose

Use this page to decide whether Clarity can move from one state to the next.

## Before Context Edits

Continue only when:

```text
the active Clarity Boundary exists
Context scope is explicit
review depth is explicit
allowed Context mutations are explicit
explicit exclusions are named
source material policy is stated
no-auto-start rule is present
```

Stop when the agent is about to edit Context without a live Clarity Boundary.

## Before Source Inventory Completion

Continue only when:

```text
source material is listed
current Context slice is listed
source treatment is explicit
stale, duplicate, conflict, and canonical candidates are named or marked none
excluded material is named with reason
unresolved source questions are recorded
```

Stop when source structure is being copied into Context without target-native
treatment.

## Before Context Review

Continue only when the Context Review Packet names:

```text
the Context surface contract being applied
route checks
content adequacy checks
canonicalization checks
promotion pressure checks
retrieval checks
freshness and review-label decisions
unresolved questions
```

Stop when route-only work is about to mark leaves reviewed without content
review.

## Before Closure

Continue only when:

```text
Context updates match the Clarity Boundary
updated Context entries satisfy the Context surface contract or are explicitly
deferred/provisional
review depth completed is stated
route and content review limits are honest
canonical, stale, duplicate, conflict, and supersession decisions are recorded
promotion pressure is recorded without silently updating narrower surfaces
retrieval proof is current or blocked with reason
recommendations are explicit
no recommendation starts another process automatically
```

Stop when a recommendation is phrased as an automatic handoff.
