# Ask

## Use When

Use this response when the next safe move depends on a founder-dev decision that
cannot be inferred from current semantic authority or Control records.
Use it when product judgment cannot be stated without inventing the behavior,
tradeoff, exclusion, or falsifier being accepted.

## Required Output

Ask for the smallest decision that unblocks the current state. Preserve the
question and blocked state in the active Control record when future work depends
on the answer.
