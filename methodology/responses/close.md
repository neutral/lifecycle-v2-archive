# Close

## Use When

Use this response when active work has no remaining required action or has been
explicitly resolved by landing, abandonment, rejection, archive, promotion, or
deferment.

## Required Output

Close the owning Control record with final state, next retrieval pointer when
needed, product judgment outcome when Delivery is closing, and
records-off-by-default treatment.

Discovery has no closure record type: a Discovery loop's closure — including
closing without selecting any work — is recorded in the owning plan map and
plan items, with each deferral or block carrying its retrieval condition. The
plan map stays active as the router while deferred or blocked work should stay
retrievable.
