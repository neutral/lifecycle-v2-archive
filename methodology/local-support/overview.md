# Local Support

## Purpose

Use this folder for run-local support interfaces that help an acting agent,
wrapper, or outside observer coordinate active Lifecycle work.

The target-codebase artifacts governed by these interfaces are gitignored local
material. They are not product authority, process state, proof, installed
discipline, product judgment, or source methodology.

## Pages

Use [work-trace.md](work-trace.md) when an active run needs a local sequence of
meaningful agent actions.

Use [stop-work-request.md](stop-work-request.md) when an external interruption
asks the acting agent to stop expanding target work.

Use [tooling-support.md](tooling-support.md) when optional tooling support
exists, is missing, is stale, or produces findings, receipts, indexes, or
prepared material.

## Authority Rule

Local support does not govern future work by itself.

Move local support content into durable records only when the interpreted fact
changes process state, product judgment, proof status, authority treatment,
closure, or learning. Rewrite that fact in the owning Control record or
semantic authority entry.
