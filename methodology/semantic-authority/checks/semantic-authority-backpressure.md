# Semantic Authority Backpressure Check

## Check

Backpressure exists when:

```text
needed product meaning is missing
needed product meaning is stale
two entries conflict
the owning surface is unclear
the active state depends on product meaning outside installed surfaces
```

## Failure Route

Use `semantic-authority/resolve-semantic-authority-backpressure.md` before proceeding.

If installed semantic authority is sufficient but the active Work Boundary lacks
product judgment, return to `states/work-boundary-active.md`. Product judgment
is Control state, not semantic authority backpressure.
