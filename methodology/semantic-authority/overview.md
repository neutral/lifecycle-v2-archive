# Semantic Authority

## Purpose

Use this folder for installed methodology operations, checks, generated
registries, generated templates, and surface contracts that retrieve, update,
and repair semantic authority.

The compiler copies operation pages and generates the semantic authority surface
registry and entry templates from the human-readable surface manifest.

Use the generated registry to select the owning surface and retrieve entries by
scope, retrieval keys, target references, state, and related semantic
authority. Use generated templates to keep product entries adequate without
turning semantic authority storage into proof logs or process history. The
generated YAML header is the shared entry contract; generated body-shape
guidance helps choose useful Markdown sections below that header.

Semantic authority supplies durable meaning for product judgment. Product
judgment itself is not a semantic authority surface; it is process-local
weighing recorded in the active Work Boundary before Delivery changes
production behavior.

## Pages

Use [surfaces/overview.md](surfaces/overview.md) to identify the semantic
authority surfaces and the durable product meaning each surface owns.

Use [surfaces/contract.md](surfaces/contract.md) when reading, writing,
retrieving, or checking semantic authority entries.

Use [surfaces/update-procedure.md](surfaces/update-procedure.md) when deciding
whether Clarity, Discovery, or Delivery should create, update, defer, or skip
semantic authority entries.

Use [retrieve-product-meaning.md](retrieve-product-meaning.md) before
clarifying Context, admitting, building, proving, or selecting work that
depends on product meaning. In Clarity, the retrieved slice should be
sufficient to support the active Context review. In Delivery, it should support
the active product judgment or expose that backpressure blocks admission.

Use [update-product-meaning.md](update-product-meaning.md) when admitted
learning, including durable learning from a closed product judgment, should
become durable product authority.

Use [resolve-semantic-authority-backpressure.md](resolve-semantic-authority-backpressure.md)
when the current semantic authority surfaces are too sparse or conflicting to
support the next move.
